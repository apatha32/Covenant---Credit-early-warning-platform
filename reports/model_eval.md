# Model card: 12-month distress model (feature set v1)

Generated by `python -m tripwire_ml train` on 2026-10-26. Data as of 2026-10-27. Model versions: LightGBM 6 (active), logistic 5, Altman 4.

## Task

For each SEC filer at each quarter end T: will the company start a bankruptcy case (8-K Item 1.03, text-checked) within (T, T + 12 months]? Features use only data filed on or before T. Companies already in bankruptcy at T are excluded. Banks, insurers, REITs, funds and shells (SIC 6000-6799) are excluded.

Hand review of a fresh random sample (not used for rule changes): 18 of 20 `petition` filings were the filer's own bankruptcy (errors: a parent filed without this registrant); about half of `unclear` filings were new insolvencies. Estimated label precision ≈ 88%. Bankruptcies never reported on an Item 1.03 8-K are missing (recall is not measured).

## Leakage check

Features are recomputed after deleting every filing, restatement and macro release dated after the as-of date; the output must be identical. It runs in the unit tests (synthetic data, including a planted leak that must be caught) and on real data during every dataset build (results in `raw.ingest_runs`, source `ml_dataset`).

## Known limitations

- Book values only: no market prices, so Altman Z'' (book-equity variant) is the baseline.
- Universe is SEC XBRL filers since 2009; dominated by small caps.
- Labels rely on Item 1.03 8-Ks; companies that stop filing before bankruptcy may be missed.
- Text-derived risk signals (Phase 5) are not in feature set v1.
- Probabilities are calibrated on 2020, an unusual year; check calibration drift (Phase 7).
